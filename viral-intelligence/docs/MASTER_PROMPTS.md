# PROMPTS MAESTROS — VIDEO INTELLIGENCE

## Prompt 1: Análisis Completo de Referencia
*"Analiza este video como un técnico de post-producción. Extrae: metadatos, FPS, codec, resolución, duración, ritmo de edición (cortes por segundo), tipo de plano por toma, movimiento de cámara, paleta de colores, BPM, energía, hook, subtítulos, sincronía audiovisual y curva de retención. No inventes datos que no puedas medir."*

## Prompt 2: Receta de Producción Original
*"A partir de los datos técnicos de este video de referencia, crea una receta de producción para un video NUEVO sobre [tema]. La receta debe incluir: formato, resolución, FPS, duración objetivo, ritmo de edición, duración media de toma, movimiento de cámara, paleta de colores, BPM de referencia, look visual, estructura narrativa (hook/desarrollo/clímax/cierre), y recomendaciones técnicas. No copiar contenido del original."*

## Prompt 3: Generar Guion Original
*"Escribe un guion de [X] segundos para TikTok sobre [tema]. Usa esta estructura: Hook (0-2s) con pregunta o resultado rápido, Desarrollo (2-Xs) con pasos claros y visuales específicos, Clímax (momento más impactante), y Cierre con CTA natural. El guion debe ser 100% original, sin copiar personas, voces, marcas ni frases de otros creadores."*

## Prompt 4: Storyboard Técnico
*"Convierte este guion en un storyboard con: número de toma, tiempo inicio/fin, tipo de plano (primer plano/medio/general), movimiento de cámara, acción visual, texto en pantalla, transición sugerida y audio. Formato tabla."*

## Prompt 5: Prompts para Generación de Imagen
*"Genera una imagen original para representar [concepto]. Formato 9:16 vertical, composición clara, contraste visual, paleta cálida/fría según [especificación], sin logos ni marcas de agua, sin imitar artistas vivos. Sujeto: [descripción]. Estilo: [definido por la receta]."*

## Prompt 6: Prompts para Generación de Video/Animación
*"Genera una animación de [X] segundos sobre [concepto]. Formato vertical 9:16, movimiento [suave/dinámico/handheld], ritmo [rápido/medio], iluminación [cálida/fría/neutra]. Mantener coherencia entre frames, anatomía correcta, sin deformaciones, sin flicker, sin texto ilegible."*

## Prompt 7: Optimización TikTok
*"Evalúa este video para TikTok y puntúa: hook (0-100), sonido (0-100), retención (0-100), formato (0-100). Para cada score menor a 70, genera una recomendación específica y accionable. No prometas viralidad."*

## Prompt 8: SEO para Plataformas
*"Genera para este video: 4 títulos alternativos (máx 60 chars), 1 descripción con palabras clave (150-300 palabras), 15 tags relevantes, y sugerencia de horario de publicación."*

## Prompt 9: Variante A/B
*"Crea 3 versiones del hook de este video cambiando solo: A) El primer segundo visual, B) La música, C) El texto en pantalla. Mantén todo lo demás idéntico para poder comparar qué variable mejora el rendimiento."*

## Prompt 10: Verificación de Originalidad
*"Compara estos dos contenidos y marca cualquier similitud en: personajes, diálogos, escenas, planos, marcas, voces o estructura. Si hay similitudes, propón cambios para que el nuevo contenido sea claramente diferenciable."*

## Prompt 11: Checklist de Producción
*"Genera un checklist de producción con estas categorías: PRE-PRODUCCIÓN (guion, storyboard, permisos, locación), PRODUCCIÓN (cámara, iluminación, audio, vestuario), POST-PRODUCCIÓN (edición, color, audio, subtítulos, efectos), PUBLICACIÓN (SEO, formato, horario, hashtags, CTA)."*

## Prompt 12: Análisis de Competencia Ético
*"Analiza los patrones TÉCNICOS de edición de este canal sin copiar contenido: ritmo promedio, paleta de colores, tipo de plano más usado, duración promedio, tipo de hook y estructura narrativa. Genera recomendaciones para diferenciarte sin infringir derechos."*

## Prompt 13: Guion para Serie de 10 Episodios
*"Convierte este tema en una serie de 10 TikToks. Cada episodio debe tener: hook propio, valor independiente, teaser del siguiente y duración de 30-60 segundos. No uses clickbait engañoso."*

## Prompt 14: Adaptación Multiplataforma
*"Adapta este contenido de 45 segundos a: TikTok (9:16, 20s), Reels (9:16, 30s), Shorts (9:16, 60s), YouTube horizontal (16:9, 3-5min). Para cada formato indica qué cambiar: encuadre, densidad de texto, ritmo y duración."*

## Prompt 15: Evaluación de Calidad Final
*"Evalúa este video en 10 dimensiones (0-100 cada una): hook, claridad, composición, continuidad, ritmo, sincronía, legibilidad, audio, originalidad y cierre. No inventes métricas de audiencia. Propón 5 mejoras concretas."*
